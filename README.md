# دورهمی‌یار — جعبه‌بازی کاغذی فارسی

۱۰ بازی فارسی در یک PWA کاغذی: آفلاین، بدون ثبت‌نام، بدون تبلیغ.
ظاهر کاغذ و مقوا با عمق ۲٫۵ بعدی، بافت واقعی و انیمیشن‌های دست‌ساز.

```bash
npm start     # http://localhost:4173
npm test      # ۱۰۴ آزمون
npm run check # یکپارچگی پروژه + آزمون‌ها
```

بدون وابستگی بیرونی، بدون `npm install`. فقط Node ≥ ۲۰.

## معماری

- **موتورهای خالص** در `public/src/engines/` — بدون DOM، کاملاً تست‌پذیر، تصادفی با seed.
- **رابط‌ها** در `public/src/games/` — هر بازی یک ماژول با `mountGame(root, { game, onExit })`.
- **محتوا** در `public/src/content*.js` — قابل گسترش بدون دست‌زدن به منطق.
- **شبکه** در `public/src/net/sync.js` — قرارداد پیام نسخه‌دار + اعتبارسنجی + revision gate.
- **سرور** در `server.mjs` — استاتیک، فقط `public/`، هدرهای امنیتی و CSP.
